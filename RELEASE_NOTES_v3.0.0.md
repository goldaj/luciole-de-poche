# Luciole de poche 3.0.0

- Nouveau nom public : **Luciole de poche**.
- Projet Android modernisé pour API 36 et publication en AAB.
- Architecture du client découpée par responsabilités ; anciens patches intégrés au code principal.
- Sauvegardes renforcées : copie de secours, récupération, export et import.
- Navigation Retour Android cohérente et protections contre les sorties accidentelles.
- Passe accessibilité : zoom, focus, lisibilité et surfaces tactiles.
- Préparation Google Play Billing 9.1.0 pour de futurs achats de Gemmes.
- Séparation stricte entre Gemmes gagnées et Gemmes achetées.
- Affichage détaillé des probabilités des Échos lorsque la boutique sera activée.
- Nouveau contrôle QA de release.

Les achats réels restent désactivés jusqu'au branchement d'une validation et d'un portefeuille serveur.
