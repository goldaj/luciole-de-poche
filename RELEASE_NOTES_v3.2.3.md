# Luciole de poche v3.2.3

- Le tutoriel de première balade explique désormais brièvement le rôle des boules de lumière, sans révéler leur évolution future.
- Les PNJ ne peuvent être touchés que lorsqu’ils sont dans le halo direct du joueur. Les zones mémorisées, les halos passifs et la brume de proximité ne suffisent pas.
- L’alerte de nouveau dialogue d’un PNJ n’apparaît que lorsque ce PNJ est directement éclairé.
- Version Android : 3.2.3 (`versionCode 101`).
