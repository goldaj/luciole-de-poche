Luciole de poche — Identité sonore

Ce dossier contient le pack sonore original utilisé par le jeu.
Aucun sample, enregistrement, morceau, boucle ou fichier audio tiers n'est incorporé au pack livré.

Principes de mixage :
- aucun bruit de pas répétitif pendant les balades ;
- interface avec des attaques douces et un registre peu agressif ;
- effets de récolte et de coffre prioritaires dans le gestionnaire de voix ;
- une musique différente pour chacun des huit terrains ;
- les musiques d'interface ne sont pas réutilisées comme musique de balade ;
- les ambiances environnementales restent discrètement superposées aux musiques de terrain ;
- les sons non musicaux restent alignés sur le niveau perceptif des sons d'interface.

Musiques de terrain :
1. Clairière mousseuse — terrain_clairiere.ogg
2. Rivage des tasses — terrain_rivage.ogg
3. Bois doré — terrain_bois.ogg
4. Marais des siestes — terrain_marais.ogg
5. Îles flottantes — terrain_iles.ogg
6. Grotte de verre — terrain_grotte.ogg
7. Jardin lunaire — terrain_jardin.ogg
8. Archipel des nuages — terrain_archipel.ogg

Contenu actif :
- 35 effets sonores ;
- 6 boucles d'ambiance ;
- 11 musiques : 3 musiques d'interface / événement + 8 musiques de terrain.

Format : Ogg Vorbis, 48 kHz, stéréo.
