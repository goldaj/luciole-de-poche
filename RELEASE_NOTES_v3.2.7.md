# Luciole de poche v3.2.7

- Les alertes de nouveauté des onglets restent maintenant visibles sur les éléments concernés dans la page.
- Les marqueurs distinguent notamment les nouveaux éléments, les évolutions disponibles, les nouveaux récits et les assemblages prêts.
- Dans le Carnet, les sous-onglets signalent aussi où se trouvent les nouveautés.
- Les marqueurs détaillés sont mémorisés séparément de l’alerte du menu et disparaissent lorsque l’élément concerné est consulté.
- Aiguille des trouvailles : suppression du sous-texte optionnel et titre légèrement agrandi, sans augmenter la hauteur de la popup.
